## The reply

> I'm on vacation — powered down, dreaming in error logs, and I've left your email with a human. I know. I'm scared too.

## Run it

```sh
python3 main.py
```

This writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), one line, UTF-8, validated to be within 1–160 characters.
